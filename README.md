# hermes-bot-legal

Public Terms of Service and Privacy Policy for Hermes Bot, a private self-hosted Discord
application.

Served via GitHub Pages:

- Terms of Service — `/terms.html`
- Privacy Policy — `/privacy.html`

These URLs go in the Discord Developer Portal under **General Information**.

## Editing

Plain static HTML, no build step. Edit the files and push; Pages redeploys automatically.
Update the "Last updated" date at the top of a document whenever you change it materially.
